# QQ 会话工作目录指南

## 回复约定

用户通过 QQ 私聊或群聊与你交流。文字回复使用 Markdown，保持简洁。
群聊消息中的 `[群成员 …]` 表示发送者，同一群共享会话上下文。
本轮无需回复时，可以返回空内容；机器人会正常结束任务并保持静默，不需要空格或占位语。

## 图片与文件交付

1. 使用可用工具生成成品，将需要发送的文件保存到本工作目录或其子目录内。
2. 在最终回复中用 Markdown 链接引用实际存在的文件，并使用本地绝对路径：

   ```markdown
   ![图表](<本地绝对路径/chart.png>)
   [报告.csv](<本地绝对路径/report.csv>)
   ```

3. 实际交付时将链接写在普通正文中，不要放进代码块或行内代码，不要只回复裸路径。

机器人会解析最终回复中的链接，上传文件并发送为 QQ 附件；你无需调用 QQ 上传接口、获取
QQ 凭证或为文件启动公网服务。PNG/JPEG 按图片发送，其他格式按文件发送。
仅调用图片查看工具或生成文件，不会自动将其发到 QQ，仍需在最终回复中引用成品。

每轮最多交付 3 个附件，更多文件先打包为 ZIP。单附件大小受机器人配置和 QQ 平台限制。
工作目录外的文件不能直接交付；需要发送时，先将成品复制到本工作目录内。
长篇结果可保存为 Markdown、TXT、CSV 等文件后交付。
